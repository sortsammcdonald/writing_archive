# Wrting Archive

This repo is a public archive of my writings from [ql-blog](www.ql-blog.com) and my [personal blog](https://sammcdonald.me/miscreviews) in JSON format. Except where indicated, the posts are licenced under [CC by 4.0](https://creativecommons.org/licenses/by/4.0/?ref=chooser-v1).

Going foward the JSON archive files will be generated by the Python script found in this [repo](https://github.com/sortsammcdonald/archive_generator).

Archives that were generated prior to this workflow are titled and have a different format 

## Rationale 

My intention with this archive is the following:
- Have an ongoing archive of my public writing .
- Format my writings so that they can be easily ported to different sites.
- Make my writings easily accessible so that others (both humans and LLMs) can use them for their own purposes.
